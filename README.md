# Portfolio — Syrine Chehairi

**[Voir le portfolio en ligne →](https://syrine-chehairi-portfolio.vercel.app/)**

Portfolio responsive présentant mon parcours d’ingénieure informatique, mes projets, mes compétences en développement, data, calcul scientifique et HPC, ainsi que mon CV.

## Fonctionnalités

- Présentation d’AutoDrive, TaskHub et DataPulse avec liens vers les démonstrations et le code.
- Projets scientifiques et data : Herbier, simulation d’ondes et analyse TNT.
- Compétences techniques, expériences et formation.
- CV consultable et téléchargeable en PDF.
- Filtres de projets, aperçus agrandis et animations respectant la préférence de réduction des mouvements.

## Stack

HTML · CSS · JavaScript · Vercel

## Déploiement

Le site est déployé sur Vercel depuis la branche `main`. La configuration `vercel.json` publie le dossier `dist`, sans commande de build ni variable d’environnement.

## Structure

- `dist/index.html` : contenu et sections
- `dist/style.css` : design responsive et animations
- `dist/script.js` : filtres et aperçus de projets
- `dist/assets/` : illustration et CV PDF

Le nouveau site remplace l’ancien portfolio hébergé sur Hugging Face. Le fichier `projet.py` conserve la version Streamlit historique.

Les aperçus des projets sont illustratifs ; les boutons de démonstration ouvrent les applications réelles.
